# ZeppBridge 视觉改造验收清单

> 用于 P3 收尾验收：与 `design_picture/` 前五张参考图并排核对。
> 环境：窗口约 1280×800、UI 缩放 100%（设置 → 外观主题）、深色模式；浅色模式单独走一轮。

## 一、全局（每页通用）

- [ ] 品牌绿为**淡绿带灰**（`#72C994` 观感），不艳、不荧光
- [ ] 背景三档层次可辨、非纯黑；卡片靠 1px 半透明边框 + 微色差区分，无阴影
- [ ] 中文为 **MiSans**（明显区别于系统微软雅黑）；数字为 **Inter** 且等宽对齐（tabular）
- [ ] 全站无小于 12px 的中文正文；无 500/600/650 等奇数字重造成的发糊
- [ ] 图标：描边统一 1.5、圆头圆角；导航/工具用描边、健康分类用实心，同区域不混用
- [ ] 侧边栏：Logo + 四项导航（概览/最近记录/交给 AI/设置）+「数据仅在本机」徽标 + 版本号，无长文案
- [ ] UI 缩放五档（80–125%）可用、Ctrl + / Ctrl - / Ctrl 0 生效、重启后保留
- [ ] 页面切换自动回到顶部

## 二、逐页核对

## 三、数据真实性回归（原需求文档功能项，均为已实现项）

- [ ] 详情页「同步时间」显示 `synced_at`，不是记录结束时间
- [ ] 设备信息与该条记录的 `device_id` 对应；融合来源显示「设备未确定」
- [ ] 在床时长无可靠字段时显示「未提供」，不推算
- [ ] GPS 不可用 / 无样本时的说明文案正确（前后端字段一致）
- [ ] 「数据来源：Zepp 云端」与「数据范围：用户融合 / 单设备 / 多来源」分开显示
- [ ] 睡眠「阶段说明」内容纯解释、无诊断
- [ ] 概览心率曲线在样本不足 2 个时不绘制

## 四、浅色模式

- [ ] 浅色 / 深色 / 跟随系统三态可切换且重启持久化
- [ ] 浅色下：文字/次级/边框/卡片/输入/hover/focus/disabled/危险/成功状态对比正常
- [ ] 浅色下心率曲线、网格线、tooltip 颜色正确（不再用暗色硬编码）

## 五、响应式

- [ ] 760px 以下：移动顶栏 + 四项底部导航正常，无横向溢出
- [ ] 1280px 基准下各页占屏比例接近参考图

2. 各页与参考图的占屏比例差异（我无法看图，需你并排核对）。
