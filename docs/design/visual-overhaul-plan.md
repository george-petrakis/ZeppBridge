# ZeppBridge 前端视觉与布局修复计划（第二轮 · 2026-08-13）

> 状态：已与需求方完成两轮共 21 个问题的逐项确认，本计划为最终执行蓝本。
> 分支：`ui-overhaul`。原则：先对齐参考图，再落地设计系统；深色优先、浅色随后；视觉完整度不能高于数据真实性。

## 1. 背景

当前界面（0.6.0）存在四类问题，且均已在代码中定位到根因：

| 抱怨 | 根因（代码证据） |
| --- | --- |
| 配色丑 | 近纯黑背景层次不可分；每张卡片带红/绿/紫 wash 底色互相打架；品牌绿 `#72C994` 与 ui-guidelines.md 的 `#3DDC84` 矛盾 |
| 字体不清晰 | 微软雅黑仅 400/700 字重，代码大量使用 500/650（触发合成粗体发糊）；10–11px 小字低于中文清晰下限；大数字用 Cascadia Code |
| 杂乱 | 图标描边(1.75)与实心混用；图表两套体系（手写 SVG + ECharts）；字号/圆角/间距各页各写 |
| 留白/布局不合理 | 页面宽度已放开但无统一标度；卡片 padding/区块间距 12/14/16/18px 随意出现 |

需求文档（`ZeppBridge 前端视觉、缩放与图标一致性改造需求.md`）中的**功能遗留项已全部实现**（同步时间语义 `synced_at`、GPS/样本字段、在床时长、设备匹配、数据来源/范围、阶段说明），本轮只需回归验证，不需要新的后端改动。

## 3. 设计系统规格 v2（目标 token）

### 3.1 色彩（暗色基准，浅色值第 5 阶段适配）

```css
/* 表面阶梯（冷调近黑，三档 + hover） */
--bg:        #0E0F11;  /* 画布 */
--sidebar:   #0B0C0E;  /* 侧栏，略深于画布 */
--surface:   #15161A;  /* 卡片 */
--raised:    #1C1E22;  /* 悬浮/输入框/菜单 */
--hover:     #232529;  /* hover 表面 */
/* 边框：半透明白，无实色线框 */
--line:        rgba(255,255,255,.07);
--line-strong: rgba(255,255,255,.12);
/* 文字四档 */
--ink:     #EDEFF2;  --muted: #A0A6AE;  --subtle: #6E757E;  --faint: #525862;
/* 品牌（淡绿带灰，参考图同感） */
--accent: #72C994;  --accent-hover: #8FD9AC;  --accent-press: #5CB37E;
--accent-ink: #0A1F12;  --accent-soft: rgba(114,201,148,.12);
/* 数据分类色（明暗共用，暗色下已提亮） */
--heart: #EF6E6E;  --sleep: #9BA3F5;  --activity: #8FCB9B;
--calories: #EF9F27;  --distance: #378ADD;
/* 状态色（与数据色分离） */
--danger: #F0616A;  --warning: #D9A556;  --ok: var(--accent);
```

旧 token（`--heart-wash` 等）**退役**：带色调的卡片 wash 不再用于卡片底色；如页面需要极轻的分类暗示，统一用 `color-mix()` 或预定义的 `--tone-soft-*`（约 8% 透明度），仅限图标容器/图表填充。

### 3.2 字体与排版

- 打包：`MiSans`（Regular 400 / Bold 700，TTF）+ `Inter`（latin 400/500/600/700，woff2）。
- 字体栈：`'Inter','MiSans','Segoe UI','Microsoft YaHei UI',sans-serif`；大数字/数值列单独用 Inter + `tabular-nums`。
- 字号阶梯：`12(下限，仅密集表格/时间戳) / 13(正文) / 14(输入框/强调正文) / 16(区块标题) / 20(小节标题) / 24(页面标题) / 28-44(显示级数字)`。
- 字重：中文只用 400/700；拉丁/数字 Inter 可用 500/600。行高 1.5（正文）/1.2（标题）/1.0（显示数字）。
- 禁止：中文斜体、11px 以下字号、奇数字重（650 等）——全站 grep 清掉。
- 授权：`LICENSE-inter.txt` + MiSans 使用许可说明随包分发；按 MiSans 要求**在软件内署名**（设置页"高级与隐私"区加一行字体署名）。

### 3.3 间距 / 圆角 / 层级

- 间距标度仅允许：`4 / 8 / 12 / 16 / 24 / 32 / 48`。卡片内边距 16，卡片间距 12（紧凑区）/16（常规），区块间距 24–32，页面内边距 24。
- 圆角：卡片/面板 12px，控件/输入 8px，chip 999px。
- 层级：无阴影；hover/浮层 = 表面提亮一档（`--raised`）。焦点环 `--accent` 2px。

### 3.4 图标规格（统一重排）

- viewBox 24；光学框 3–21；**线宽统一 1.5**；圆头圆角；拐角半径统一 2px。
- 规则：导航/工具类 = 描边；健康分类 = 实心剪影（细节度以 16px 可辨为上限）。同一区域绝不混用两种语言。
- 尺寸规格：12/14/16/18/20/24，以 4 为步进取用。
- 同步更新 `docs/design/zeppbridge-icon-system.md`。

### 3.5 ECharts 统一主题

- 新建 `src/lib/echarts/theme.ts`，注册主题 `zeppbridge`（暗色）与 `zeppbridge-light`：
  - 字体 `Inter, HarmonyOS Sans SC`；`textStyle` 颜色走 token；
  - 折线 2px 圆头，面积渐变 35%→0；
  - 网格线 `rgba(255,255,255,.05)` 虚线，轴线隐藏；刻度标签 11px `--subtle`；
  - tooltip：背景 `--raised`、边框 `--line-strong`、无阴影、数字 tabular；
  - 图例用自绘方形色块（小），默认关闭；
  - 分类色顺序：heart / sleep / activity / calories / distance。
- 概览页心率曲线由手写 SVG 换成 `VChart`（LineChart + areaStyle + Tooltip），保留"无样本不画曲线"逻辑。

## 7. 风险与回滚

1. **字体体积**：MiSans 两字重 TTF 约 17MB（官方 zip 227MB，仅取 Regular/Bold）。如你不接受 → 回退系统字体栈方案（已达成一致的回退路径）。
2. **WebView2 CJK 渲染偏淡**：老版本 runtime 的 Skia contrast 问题与字体无关；验收时若中文仍发虚，先升级 WebView2 runtime 再判断。
3. **参考图不可见**：本会话模型不能看图，参考图细节（绿色色相、具体占屏比例）由你在验收时核对并文字反馈，我按反馈微调。
4. **CSS `zoom` 缩放**：先保证 100% 基准与参考图一致，再验证 80/90/110/125 档。
5. **浅色模式过渡期**：P1–P2 期间浅色可能暂时错位（已接受），P3 统一适配。
6. **数据真实性红线**：任何视觉改动不得引入推算/模拟数据。
