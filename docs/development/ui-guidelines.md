# ZeppBridge UI 设计与交互约束

更新时间：2026-08-15（重构里程碑完成）。ZeppBridge 是用户的穿戴健康数据桥梁，不是臃肿的分析 App。视觉采用军事风暗色橄榄绿设计系统，强调色为低饱和品牌绿 `#CDDC7C`（背景 `#12140D` / `#14160C` / `#1B1E12`），不使用泛滥的紫色或高饱和荧光色。

字体：打包 MiSans（中文，400/700 两字重）+ Inter（拉丁/数字，tabular-nums）；中文不使用 500/600 等中间字重以避免伪粗体发糊，层级通过字号与明度划分。

## 核心原则

- **同步可信**：云端拉取时间、同步状态和设备时序健康样本时间必须明确分开表达。
- **真实优先**：缺失值显示 `未提供` 或明确空状态，绝不使用假数据、零值或模拟曲线填空。
- **分析外置**：专业医学与运动建议交给用户自由选择的 AI 工具，应用自身专注数据采集、标准化存储、脱敏保护与 AI-ready 导出。
- **隐私底线**：
  - 导出到 AI 时默认执行不可逆脱敏（抹除 device_id、MAC、IMEI、精确 GPS 等敏感字段）；
  - 数据包体积 > 2 MiB 时自动写入系统桌面 `zeppbridge-ai-handoff.json` 并向剪贴板写入拖入提示；
  - GPS 轨迹仅在本地离线 Canvas/SVG 绘制，绝不请求第三方在线地图瓦片。
- **渐进披露**：日常使用展示核心就绪度和快捷复制；高级设置、数据库路径、认证清理默认折叠收敛。

## 页面架构

主导航四项：探索 (`/`)、导出与提示词 (`/explore`)、最近记录 (`/recent`)、设置 (`/settings`)。

### 1. 探索 (`/`)
- Hero 价值卡：安全（Secure）、私密（Private）、AI 就绪（AI-ready）。
- 流程示意条：Zepp Cloud → ZeppBridge → AI 工具。
- 设备卡与云服务状态卡：显示识别到的实体设备与 Zepp Cloud 同步情况。
- 最新数据包与 AI 交接就绪度环（CircularProgress）+ 4 项安全承诺横条。

### 2. 导出与提示词 (`/explore`)
- 自绘深色日历弹层选择器，支持 7 天 / 30 天快捷与月份点选。
- AI 提示词模板快速切换与一键复制。
- 7 款主流 AI 助手（ChatGPT、Claude、DeepSeek 等）一键网页直达。

### 3. 最近记录与详情 (`/recent`, `/workouts/:id`, `/sleep/:id`)
- 两列排版，计数口径统一；过滤数据时显示透明隐藏提示。
- 运动详情：ECharts 垂直渐变填充 + 虚线均值线、本地 GPS 速度色谱图、横向心率区间条。
- 睡眠详情：深紫/浅蓝紫/REM绿/清醒红阶段色；近 7 天每日睡眠时长堆叠周柱状图。

### 4. 设置 (`/settings`)
- 2 列 + 3 列卡片网格。
- 官方网页登录 / HAR 导入 / 手动认证。
- 导出格式本地持久化与自动同步间隔调节。
