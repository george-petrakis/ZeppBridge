# ZeppBridge 连接指南

本页只说明 ZeppBridge 设置页里的连接流程。优先使用应用内置捕获；文档是故障恢复和高级回退，不是第一次启动的必读教程。

## 先了解三件事

- 手机和电脑必须在同一个 Wi‑Fi。请不要把代理端口暴露到不可信网络。
- token 能访问你的健康数据。不要把 token、完整请求头、HAR 或二维码截图发到公开渠道。
- Android 7+ 通常不会让普通应用默认信任用户安装的 CA；厂商 ROM 可能更严格，Zepp 还可能启用证书固定。因此内置捕获不是成功保证，也不应该通过 root、破解或 patch 绕过这些限制。

## 推荐流程：应用内置捕获

### 1. 在电脑启动捕获

1. 启动 ZeppBridge，进入“设置”。
2. 确认电脑和手机连接同一 Wi‑Fi。
3. 点击“开始捕获”。默认端口是 `8888`；如果该端口被占用，可以在页面改成另一个 `1024–65535` 的端口。
4. 记下页面显示的 **本机地址（LAN IP）** 和 **端口**。请使用页面给出的 LAN IP，不要把 `127.0.0.1` 填到手机上。

代理会绑定电脑的局域网监听地址。它只对 `api-mifit*.zepp.com` 和 `api-mifit*.huami.com` 进行 HTTPS MITM；其他 CONNECT/TLS 目标保持隧道转发，不会被解密。

### 2. 用手机取得并安装 CA

1. 用手机扫描页面上的证书二维码，或在手机浏览器打开页面显示的证书 URL（形如 `http://<LAN-IP>:<端口>/zeppbridge-ca.cer`）。
2. 下载 DER 格式的 `.cer` 文件。
3. 打开手机系统的“安全/加密/证书”设置，选择安装 CA 或用户证书，并按系统要求完成锁屏验证。
4. 在系统里确认该 CA 已被信任。不同 Android 版本、厂商 ROM 和工作资料空间的入口名称不同。

如果系统不允许用户 CA，或 Zepp 仍然拒绝 TLS，请不要尝试绕过证书固定。可以移除本次证书后切换到本页末尾的手动回退，或者暂时停止使用捕获流程。

### 3. 设置手机 Wi‑Fi 代理

在手机当前 Wi‑Fi 的代理设置中选择“手动”，填写：

```text
代理主机：ZeppBridge 页面显示的 LAN IP
代理端口：ZeppBridge 页面显示的端口
```

不要填 `127.0.0.1`、电脑的 VPN/虚拟网卡地址或旧端口。若手机无法访问证书 URL，先检查是否同一 Wi‑Fi、Windows 防火墙是否阻止该端口，以及路由器是否开启客户端隔离。

### 4. 在 Zepp 触发请求

1. 保持 ZeppBridge 捕获页打开。
2. 打开 Zepp，进入健康数据、睡眠或运动页面并下拉刷新。
3. 页面会轮询捕获状态，并分段显示“手机连接 / Zepp API / HTTPS / 认证字段”四个阶段。捕获到同一 Zepp 区域 host 上的 `apptoken` 与用户 ID 后，会显示脱敏摘要。
4. 如果只看到 token、还没有 user ID，页面会显示“补充用户 ID”。只填写 Zepp 用户 ID 即可，已捕获的 token 会沿用，不需要复制或再次输入 token。用户 ID 常见于 Zepp“个人资料 / Profile”页顶部，部分版本位于“个人资料 → 反馈 / User Feedback → User ID”；入口会因版本不同而变化。
5. 应用会用最近两小时的真实心率请求验证认证；验证成功后，设置页会启动首次同步并逐条显示各数据流状态。

空响应只能表示该时间窗没有样本，不能把 HTML、标量或失败响应当作“连接成功”。核心数据流失败时，同步报告会保持失败状态，不会假装全绿。

### 5. 收尾（必须做）

同步结束或你决定放弃时：

1. 立即把手机 Wi‑Fi 代理恢复为“无”。
2. 回到 ZeppBridge，点击“取消捕获”（即使页面已经显示同步完成也要点击）。这会停止监听器；CA 私钥留在 Windows Credential Manager 以便后续停止/重启复用，公开 `.cer/.pem` 文件可能仍留在应用数据目录，必要时可手动删除。
3. 建议从手机系统移除本次安装的用户 CA，尤其是在共享设备上。
4. 确认 Zepp 能在无代理状态下正常使用，再关闭应用。

## 手动方式（高级回退）

仅在你已经通过自己控制的、合法且符合 Zepp/设备安全策略的流程取得 token 和用户 ID 时使用：

1. 在连接页切换到“手动方式”。
2. 填写 App token、用户 ID 和实际区域 HTTPS 原点。
3. 区域地址只能是 `https://api-mifit*.zepp.com` 或 `https://api-mifit*.huami.com`，不能带端口、路径、查询参数、fragment 或凭据。
4. 点击“保存认证”，再点击“验证连接”。token 只会写入 Windows Credential Manager；状态页不会显示完整 token。

手动方式不提供绕过证书固定、root、破解 APK、patch Zepp 或伪造响应的指导。若 token 来源不明，宁可不要导入。

## 常见故障

| 现象 | 先检查 | 仍失败时 |
| --- | --- | --- |
| 手机打不开证书地址 | 同一 Wi‑Fi、LAN IP、端口、防火墙、路由器客户端隔离 | 取消捕获并重新启动；不要使用 `127.0.0.1` |
| 证书能下载但 Zepp 无请求 | 手机代理是否仍为“手动”、Zepp 是否真正刷新、系统是否信任 CA | Android/厂商策略或 Zepp 证书固定可能阻止内置捕获 |
| 捕获到请求但验证失败 | 区域 host 是否为页面捕获的原点、token 是否已过期 | 重新登录 Zepp 后重新捕获，或使用合法 token 手动回退 |
| 只捕获到 token、没有用户 ID | 按页面提示填写用户 ID；token 会在本次捕获内沿用 | 到 Zepp“个人资料 / Profile”顶部或“个人资料 → 反馈 / User Feedback → User ID”查找；入口因版本而异 |
| 端口启动失败 | 端口是否被其他程序占用、Windows 防火墙是否拦截 | 换一个端口并重新填写手机代理 |
| 睡眠显示“未验证/不可用” | `band_data` 可能是压缩或编码 payload | 当前只保留 raw，不伪造睡眠阶段；等待真实 fixture 支持 |
| 同步只完成一部分 | 查看设置页的数据流状态和错误信息 | 核心流失败时重试或重新验证；可选流不可用不等于其他数据丢失 |

## 清除认证与本地数据

- “清除认证”会停止代理、删除 Windows Credential Manager 中对应用户的 token、删除认证元数据，并重置内存中的连接状态；它**不会**删除已有健康数据库。
- “清除认证”也不会删除 `com.zeppbridge.ca` 中的 CA 私钥或重置 CA。当前没有 UI reset CA；只有显式重置凭据或删除应用数据等操作才可能让手机需要重新安装证书。
- 设置页可选择本地保留 1–365 天（默认 365）。成功同步后按该天数清理；手动「清理旧数据」用同一个天数，不可撤销。
- 需要完整删除时，先在设置页清除认证，再使用“打开数据文件夹”确认应用数据目录；请先备份后手动删除数据库和公开证书文件。
